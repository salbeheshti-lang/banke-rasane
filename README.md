# بانک رسانه - Bank Rasane

نرم‌افزار جامع مدیریت برنامه‌های تلویزیونی با ۵۸۷ برنامه در ۹ ژانر مختلف.

## ✨ ویژگی‌ها

- 🎬 **۹ ژانر متنوع**: دکور برنامه‌ها، ریلیتی شو، مستندها، خبری، مصاحبه، کودک، ورزشی، موسیقی، آموزشی
- 📊 **۵۸۷ برنامه**: کاتالوگ کامل با قابلیت جستجو و فیلتر
- 🔍 **جستجوی پیشرفته**: در عنوان، توضیحات، تهیه‌کننده، کارگردان
- 🎚️ **فیلترهای متعدد**: همه / بدون بیننده / با بیننده / با تصویر
- ↕️ **مرتب‌سازی**: جدیدترین، قدیمی‌ترین، الفبایی، بیشترین بیننده
- 🗂️ **دو حالت نمایش**: شبکه‌ای (Grid) و لیستی (List)
- ✅ **حالت انتخاب چندتایی**: برای کار روی چند برنامه همزمان
- 📄 **خروجی PDF**: با پیش‌نمایش (Pure JavaScript - بدون Python)
- 📊 **خروجی Excel**: با دو شیت برنامه‌ها و خلاصه (Pure JavaScript)
- 📱 **کارت شبکه اجتماعی**: تصویر ۱۰۸۰×۱۰۸۰ با ۸ پلتفرم
- 🌙 **تم سینمایی تیره**: با گرادینت سبز و افکت‌های نوری
- 🌐 **پشتیبانی کامل RTL**: فارسی و انگلیسی

## 🛠️ تکنولوژی‌ها

- **Electron** - فریم‌ورک اپلیکیشن دسکتاپ
- **Next.js 14** - فریم‌ورک وب (با webpack)
- **Prisma** - ORM با SQLite
- **TypeScript** - type safety
- **Tailwind CSS** - استایلینگ
- **jsPDF** - تولید PDF در pure JS
- **ExcelJS** - تولید Excel در pure JS

## 🚀 نصب و اجرا

### پیش‌نیازها
- Node.js 18 یا بالاتر
- Bun (پیشنهادی برای سرعت بالا)

### اجرای توسعه
```bash
# نصب وابستگی‌ها
bun install

# آماده‌سازی دیتابیس
bun run db:push
bun run db:seed

# اجرای محیط توسعه
bun run dev
```

### بیلد production
```bash
# بیلد Next.js
bun run build:next

# بیلد EXE ویندوز
bun run build:electron
```

فایل خروجی در `release/BankResaneh-Portable-1.1.0.exe` قرار می‌گیرد.

```
│   │   ├── page.tsx       # صفحه ورود

│   │   └── api/           # API routes
│   ├── components/        # کامپوننت‌های React
│   └── lib/               # utility ها
├── build/                 # آیکون و منابع بیلد
├── scripts/               # اسکریپت‌های کمکی
└── package.json
```

## 📦 خروجی EXE

- **نوع**: Portable (بدون نیاز به نصب)
- **حجم تقریبی**: ~300-500 مگابایت
- **سیستم‌عامل**: Windows 10/11 (x64)
- **اولین اجرا**: فایل از حالت فشرده خارج می‌شود (چند ثانیه)
- **اجرای بعدی**: سریع و فوری

### هشدار ویندوز
به دلیل عدم وجود گواهی دیجیتال، ویندوز هشدار "untrusted publisher" نمایش می‌دهد.
برای عبور: `More info` → `Run anyway`
