# Image research batch: records #411–573

## Scope and status

The earlier research documentation covered the first-pass range through #410 and later batches beginning at #574. This left a documentation gap of 135 decor-filter records in the #411–573 numeric range.

This document records a targeted final sweep of notable titles in that range. It is **not** a claim that all 135 records have been individually reviewed.

- Decor-filter records in this range: 135.
- Verified and added in this sweep: 5.
- Remaining records in this range requiring individual source/license review: 130.
- Images added: external Wikimedia Commons URLs; creator/license details are duplicated in docs/PROGRAM-IMAGE-ATTRIBUTION.md and public/IMAGE-CREDITS.md.

## Candidates rejected or deferred

- **#508 Late Night with Seth Meyers:** a set image exists, but the Commons file page displayed a pending license-review notice. It was not used.
- **#444 The View:** one candidate had conflicting rights/reuse statements; another was a group photograph from a live taping rather than a decor-focused set view. Neither was used.
- **#461 Tonight Show:** a promising image was specifically from the Conan O'Brien era, while the catalog record does not specify a host or era. It was not applied to the generic record.

## Remaining work

The remaining 130 records in #411–573 are still pending individual source and license review. Continue with exact show-name searches across Wikimedia Commons and other openly licensed archives; reject copyrighted press-kit images, presenter portraits, logos, unrelated venues, and generic studio photographs. Do not infer that a record has a usable image merely because its legacy local path is non-empty—the UI intentionally skips those old poster paths.
