# BankResaneh — Image Credits and Licenses

This file is distributed with the application so users can identify the creators and license terms for externally sourced program-set and production-environment images.

The records below identify the catalog show number, original Wikimedia Commons file, creator, source URL and reuse license. Images are linked to the original files and are not modified unless explicitly stated. Duplicate catalog records may reuse the same image; each unique source is credited once.
